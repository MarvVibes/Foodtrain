# FoodTrain 🍗🔥

> **Flame-Grilled Nigerian Food & Fast Delivery Platform**  
> Inspired by top gourmet culinary institutions, delivering smokey authentic Nigerian suya, asun, flame-grilled chicken, and party jollof across Lagos, Abuja, Ibadan, and Port Harcourt.

---

## 🌟 Key Features

- **Gourmet Brand Aesthetics:** Styled in Nigerian Gourmet Emerald Green (`#0D7A42`), Crisp White, and Honey Gold (`#F59E0B`) with Outfit and Inter typography.
- **Downtown Grill Signature Design:**
  - Compact multi-slide hero carousel with authentic Kano Yaji flame grills.
  - Refined single-line trust strip with smooth mobile touch scrolling.
  - Circular food disc cards with scalloped sunburst seals and prep badges.
  - Full-bleed category photography cards with rich dark vignette overlays.
  - Curated bestseller signatures with full-menu explore callouts.
- **Interactive Ordering Experience:**
  - Multi-branch selection (Lekki Phase 1, Ikeja Allen, Abuja Wuse II, Ibadan Bodija, Port Harcourt GRA).
  - Real-time cart drawer with free delivery meter and instant quantity controls.
  - Item customizer modal for spice levels (Mild, Medium, Extra Hot, Suya Pepper), sides, and extras.
  - Seamless checkout supporting Bank Transfer, Debit Card/USSD, and 1-Click WhatsApp direct ordering.
  - Live GPS-style simulated order tracker timeline.
  - VIP Catering budget estimator with instant guest and package calculations.
  - Digital Gift Card customizer studio.
- **Ultra-Responsive Mobile Suite:**
  - Ample padding and margin architecture (no edge-hugging elements).
  - Fixed mobile bottom navigation dock with automatic footer clearance.
  - Floating WhatsApp concierge widget.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Icons:** Lucide React
- **Styling:** Custom Modular CSS with CSS Variables & Responsive Tokens

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/MarvVibes/Foodtrain.git

# Navigate to project directory
cd Foodtrain

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Building for Production

```bash
npm run build
```
